# GradientASCII (React Bits)

Fuente oficial: reactbits.dev (variante JS + CSS). Laureano la eligió como fondo de la historia de synx build,
en lugar del degradado azul oscuro → blanco de la v3.

Props elegidas:
- colors: ["#0015ff", "#f6f8ff", "#a5d8ff", "#38bdf8"]
- shape: "horizon"
- characters: " =+xX0S8#@"
- cellSize: 18
- density: 0.8

Defaults relevantes: glyphOpacity 0.85, gradientOpacity 0.9, glow 0.2, flicker 0.2, softness 0.5, scale 1,
flow 0.5, speed 1, grain 0.08, intro true (2.4 s), fontFamily "Geist Mono".
Anima en tiempo real (rAF, mouse, matchMedia): para HyperFrames se porta con el tiempo del timeline.
